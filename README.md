# WordKid English

Небольшое офлайн-приложение для самостоятельного изучения английских слов ребёнком.

## Возможности
- 200 стартовых английских слов с русским переводом.
- Карточки для знакомства со словами.
- Русский → английский: ввод ответа с клавиатуры, проверка правописания.
- Английский → русский: выбор из четырёх вариантов.
- На слух: произношение через системный Android Text-to-Speech и ввод английского слова.
- Повтор ошибок в рамках тренировки.
- Добавление своих слов.
- Массовый импорт строк формата `english=русский`.
- Удаление пользовательских слов.
- Общая статистика правильных и ошибочных ответов.
- Все данные хранятся локально, интернет приложению не требуется.

## Сборка
Требуются Android SDK 35, JDK 17+ и Gradle 8.9 (или совместимая версия).

```bash
gradle assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
